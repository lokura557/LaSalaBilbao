## Cómo trabajamos

- `main` es producción: solo se actualiza desde una rama `release/...` o `hotfix/...`.
- `develop` es integración: todas las ramas de trabajo salen de aquí y vuelven aquí con un pull request.
- Ninguna rama entra en `develop` o `main` sin la aprobación de otra persona del equipo.
